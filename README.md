# **Set Up Your Own Local AI Helper in VS Code (Claude, Gemini, or Codex/Copilot)**

Welcome! 👋  
If you can use a web browser, you can do this.

Think of it like this:
- **VS Code** is your **digital notebook**.
- The AI assistant is your **helpful pen** that can think with you.
- This guide helps you plug that pen in, step by step.

---

This is for people with **zero technical background** who want a local AI helper in VS Code for writing, organizing, and simple automation.

You do **not** need to be a programmer to follow this guide.

## **Before You Start (2-minute checklist)**

- A computer (Windows, Mac, or Linux)
- Internet connection
- A free or paid account for the AI you choose:
  - Anthropic (for Claude)
  - Google (for Gemini)
  - GitHub (for Copilot/Codex-style workflows)

---

## **Step 1: Install VS Code**

1. Go to the official VS Code website.
2. Download the version for your computer.
3. Install it like any normal app.
4. Open VS Code.

✅ Done! You now have your "digital notebook."

---

## **Step 2: Install the AI Extension in VS Code**

1. Open VS Code.
2. Click the **Extensions** icon (looks like small blocks) on the left.
3. Search for the tool you want (Claude, Gemini, or GitHub Copilot).
4. Click **Install**.

Think of extensions like adding a new app feature inside VS Code.

---

## **The Big Three Setup (pick one or set up all three)**

Each one is only **3 steps**.

### **A) Claude (Anthropic) — 3 Steps**

1. **Create or sign in to your Anthropic account.**
2. **Get your API key** (this is like a private password that lets VS Code talk to Claude).
3. **Paste that key into the Claude extension settings in VS Code.**

That’s it. Claude is ready to chat inside your editor.

---

### **B) Gemini (Google) — 3 Steps**

1. **Create or sign in to your Google account** (and enable Gemini access).
2. **Create an API key** in Google AI Studio (again, think of this as a private connection password).
3. **Paste the key into your Gemini extension settings in VS Code.**

Done. Gemini can now help from inside VS Code.

---

### **C) Codex / GitHub Copilot — 3 Steps**

1. **Create or sign in to your GitHub account.**
2. **Install the GitHub Copilot extension** in VS Code.
3. **Click “Sign in” when prompted** and approve access.

Now Copilot is connected and ready to assist while you type.

Great question. Here are beginner-friendly, real outcomes:

In short: your AI assistant can be your **coach, writer, organizer, and second brain**.

## **Troubleshooting (Simple Fixes)**

If something is not working:

1. **Restart VS Code.**
2. **Check you are signed in** to the right account.
3. **Re-copy your API key** carefully (no extra spaces).
4. **Open extension settings** and confirm the key is pasted in the correct place.
5. **Try a simple prompt** like: “Say hello.”

If it responds, your setup is working.

---

## **Safety and Privacy Basics**

- Do not paste private passwords or sensitive personal data unless you trust the tool and account settings.
- Treat AI like a smart assistant, not a final authority.
- Always quickly review important output before sending or using it.
